# Tractor Tracker — mobile app

Expo SDK 58 / React Native app. See the main [README](../README.md) for setup, demo data and APK builds.

```bash
npm install
cp .env.example .env   # set EXPO_PUBLIC_API_URL to your backend, ending in /api
npx expo start
```

Checks: `npm run typecheck`, `npx expo lint`, `npx expo-doctor`.
